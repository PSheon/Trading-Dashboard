# 跟單文案更新

Paul 指示更新專案仍寫「未來將推出跟單功能」的文案。

- 更新關於頁、FAQ繁中及英文來源與同步產物；其他長文語系使用英文 fallback。示範公告移除「跟單即將推出」。
- 說明模擬／測試網／正式模式與帳戶選單可用性。正式模式須平台開放並符合帳戶資格，不將後端支援宣稱為正式網全面驗收或全面開放。
- 關於頁不再只描述模擬投資組合；FAQ分別說明模擬成交與實際授權／入金／風控，以及停止與退款入帳是不同狀態。
- 移除FAQ固定10組／100USDC的過時通用限額，改以模式與確認頁的當前限額為準；正式模式費用以確認及簽署內容為準，不承諾將來費率。
- 區分受限交易代理與另行授權的自動返還，避免與現行返還功能矛盾。尚未提供的電子郵件入口仍保留「即將推出」。
