## 第 4 批：研究流程首批（2026-10-01，本地）

- `/explore/all` 加入已收錄交易者搜尋：KOL／榜單名稱、X 帳號（可加 `@`）、地址前綴；每次最多 20 筆，超過時要求縮小查詢。特殊 LIKE 字元視為文字，查詢有 2 秒時限。
- 沒有榜單績效的 KOL 仍可搜尋，但只呈現身分資料與「尚無榜單績效」，不補造財務數字。來源標記不代表驗證身分；此搜尋獨立於下方績效篩選。
- `/favorites` 加入私人分組新增／改名／刪除與成員管理，每人最多 20 組、名稱最多 40 字且不分大小寫去重。同一收藏可加入多組；取消收藏會清除其群組關聯；刪除群組保留收藏與提醒。
- API 與資料庫 composite foreign keys 同時限制群組／收藏屬於同一使用者；使用者列鎖避免並發建立超額群組。通知條件、提醒配額與近期動態仍以全部收藏計算，介面明示動態範圍。
- migration `0015_private_favorite_groups` 僅在本地隔離測試資料庫執行。驗證從空資料庫建立、重複及並發 migration；沒有操作遠端 DB。
- 順帶修正動態表格展開的 ARIA 語意，改由可鍵盤操作的按鈕表達展開狀態。
- 驗證：API 78 檔／807 項、Web 30 檔／119 項通過；API build、前後端 typecheck、相關 lint、OpenAPI 契約檢查與 4 項離線測試通過。1440px／375px fixture E2E 共 2 項通過，含搜尋、分組 CRUD、保留收藏、無水平頁面溢位及 axe 檢查。後端 HTTP／隔離 PostgreSQL 測試另驗證跨使用者拒絕、多組關聯、取消收藏 cascade、並發上限與字面查詢。
- 瀏覽器使用 Demo fixtures，不是實際 Privy／正式資料整合驗收；沒有新增 CopyDog 同期外部數值對帳。手機完整產品流程、收藏四頁籤、真實通知仍待後續驗收。開發伺服器仍有既存 Privy optional Farcaster module 警告，這批未處理該整合。
- 分支狀態：`dev`，HEAD `04991f3`；先前 Admin 2–3 與本批變更仍未提交。本輪沒有 rebase、commit、push 或部署。既有 Stage 保留；使用者本地確認及明確授權前不得發布。
- 本地檢查路徑：`/explore/all`（搜尋已收錄名稱／X）及登入後 `/favorites`。實際 API 模式需先將 migration 套用到確認過的本地資料庫；不要沿用任何遠端 `DATABASE_URL` 進行本地測試。
- 後續保留：研究流程剩餘驗收、Admin 第 4 批交易者／來源／匯入預覽、模擬／testnet 跟單閉環、七類 cohort、同步截止時間的公式／數值對帳。不得將本批完成解讀為全功能等同 CopyDog。
