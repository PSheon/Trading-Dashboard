## 第 1 批紀錄

- 原版首頁與 `/dev` 共用歷史 ROI 示意計算；移除首頁獨立裁切公式。
- ROI 不可用顯示「—」及原因，不呈現零收益；無可用曲線時保留已知結果並顯示空狀態。
- 明示非逐筆跟單回測，未模擬執行成本與延遲；保留原版樣式與動畫。
- 新增原版 Calculator 渲染回歸：缺 ROI、平坦曲線與負收益；先觀察前兩項失敗，再修正。
- 狀態僅指本地變更；本批未部署、未修改資料庫或執行交易。
- 驗證：Web 完整 26 檔／112 項測試通過；型別檢查發現測試 fixture 的 Date／wire string 不符，修正後 typecheck、3 項首頁回歸與 lint 通過。未額外執行瀏覽器視覺驗收。
- 後續接第 2 批。

## 第 2 批紀錄

- 首頁與探索共用 coverage 說明，補清楚候選池選樣條件、分批更新與計算時間的意義，連結方法頁。
- 交易員頁（含手機）共用同一份模型估算聲明；不將複製評分解釋成全市場百分位。
- 交易分析對未知截止時間明示未知；即使沒有新版 backfill metadata，truncated 資料仍揭露來源歷史限制。回補完成也保留此限制。
- 方法頁移除全面對齊競品的過度聲明；補上同一份候選池／評分說明、原始歷史與 funding 覆蓋、缺值與時間語意。繁中／英文同步。
