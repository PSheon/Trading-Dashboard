# 推薦返佣規則建議與實作界線

使用者授權：2026-10-03「給我建議，不然就參考 copydog」。以下規則是本專案的建議設定，並非宣稱 Copydog 私有返佣規則已被確認。

## 已確認的 Copydog 行為

[官方 FAQ](https://copydog.xyz/help) 公開說明：無訂閱費，跟單成交收取名目金額 0.1% builder fee，另有交易所費用；每位交易員最低配置 100 USDC。前端應用專屬程式包含個人推薦碼、綁定、好友、返佣餘額及申領 API，詳見 [公開功能證據](evidence/copydog-feature-evidence-2026-10-03.json)。此次沒有找到可確認返佣比例、申領門檻、實際付款供應商的官方公開規則；未登入或操作 Copydog 付款。

## 建議採用的預設規則

| 項目 | 建議 |
| --- | --- |
| 平台交易費 | 跟單成交名目金額 0.1%；建立策略時明示，簽署 builder 授權後才可收取 |
| 返佣來源 | 被推薦人跟單產生、可歸因且已確認收取的平台 builder fee；排除入金本金、交易所費、funding、紙上成交及未收到的預估費用 |
| 比例 | 平台費用收入的 20%，單層推薦；以比例快照記錄每筆歸因，後台改規則不追溯既有收益 |
| 歸因 | 同一帳號只能綁定一次，在首次實盤跟單前綁定；禁止自我推薦、循環推薦及改碼回溯以前的成交 |
| 申領門檻 | 可用返佣至少 5 USDC；允許使用者一次申領全部可用額 |
| 收款帳戶 | 本人經驗證的 Hyperliquid 主帳戶；第一階段不接受任意第三方地址 |
| 支付路線 | 平台獨立 treasury 經 Hyperliquid USDC 內轉支付；不需要將每筆返佣橋接到外部鏈。Signer 必須只屬於平台支付角色，與跟單 agent 分開 |
| 支付費用 | 建議平台承担，申領確認頁顯示使用者實際收到的額度；若無法核實費用／可用財庫餘額，保持待處理，不猜測費用 |
| 可用性 | 記帳、申領及支付分開開關；沒有實際成交歸因和 treasury/provider 設定時，支付停用，不顯示虛構的可領餘額 |

範例：被推薦人累計跟單成交 10,000 USDC；以 0.1% 計平台費用 10 USDC；確認該收入後，推薦人累積 2 USDC。被推薦人的入金、獲利或虧損本身不增加返佣。此為費用算式示例，不是交易回報預測。

## 資料與金流要求

1. 個人推薦码屬於本站帳號，不使用 admin 的 Hyperliquid exchange referral code 代替。好友列表只顯示允許分享的名稱／匿名識別，不透露 email 或私有策略。
2. 綁定與每筆收益保存歸因時間、來源 network、帳戶、成交唯一識別、原始 builder fee、比例／政策版號、證據 digest；同一來源成交最多入帳一次。不能以平台整體 revenue counter 差額猜測各人的返佣。
3. 使用十進位／整數精確運算，保留小額返佣餘數；不能對每筆小額成交先四捨五入到六位而永久吃掉收益。可支付額度才折算六位 USDC，餘數留在帳內。
4. 狀態至少區分待確認收益、可用收益、申領保留、支付未知、已確認收款和確定拒絕；退款／更正以反向帳項記錄，保留原始證據。
5. 申領金額、收款主帳戶、network、nonce 為不可變意圖；送出之前先持久記錄 attempt；逾時只查原操作，絕不重簽另一筆支付。交易所接受不是收款確認。
6. 停用／撤權阻止新的支付；已嘗試的支付仍須只讀對帳。未知支付不能讓同一保留餘額再次申領。
7. 需要後台政策版號、audit log、待處理操作與差異檢視；每次修復保存理由，不能直接修改可用餘額以掩蓋未知操作。

## 尚未完成的驗收

個人推薦碼、綁定、好友隱私、精確小額記帳、不可變政策快照、申領歷史及使用者介面已實作，並有隔離資料庫與前端測試。公開 builder fee 檔案的解析器會保留來源證據；沒有可驗證的個人歸屬時，不會以平台總收入推算個人返佣。

真實 builder fee 收取與個人歸屬、後台政策管理、平台 treasury、支付及原操作對帳尚未完成驗收。實際收取、申領與付款保持停用，可領餘額不會由紙上成交生成。這些測試未執行任何真實授權、收費、轉帳或付款。
