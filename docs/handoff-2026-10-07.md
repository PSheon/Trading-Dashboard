## 1. 專案與目標

**Orbie**（app.orbie.fun）是 Hyperliquid 跟單平台：功能對齊 CopyDog，UI 用 Orbie 自己的設計。

**技術架構：** pnpm + Turborepo monorepo，分支一律用 `dev`。
- `apps/api`：Nest。同一個 image 依啟動參數跑 api 或 worker。
- `apps/web`：Next 16。
- `packages/shared`：Drizzle schema、migration、zod contracts。

**現階段目標：** 在 Stage 上用 Paul 的帳號做主網真錢小額跟單測試，條件如下：
- 每筆跟單預算 ≤ 50 USDC；
- 固定金額，每筆 12–15 USDC；
- 槓桿 ≤ 3x；
- 最多 2 筆。

測試順序固定，見 `docs/stage-test-flow-2026-10-07.md`：
- **A 段：** 不花錢的檢查。已完成，問題都已修正並部署。
- **B 段：** testnet 自動化測試台。必須全綠才能進 C。
- **C 段：** 主網真錢。

## 7. 已知的陷阱

- **zsh 不會自動拆字：** 迴圈清單要用陣列，`F=(a b)`，再 `for f in $F`。
- **`gh run watch`：** 前景執行可能被權限系統擋下，改在背景跑，或改用 `gh run list` 查。
- **主網跟單第一次入金會被收 1 USDC 開戶費**（50 實際到帳 49），畫面上顯示 −$1.00 是正常的。
- **Hyperliquid 規則：**
  - 每單最低 10 USD；只有剛好全平的 reduce-only 單例外。
  - 新帳戶預設是 cross 20x，所以下單前一定要先設槓桿。
- **Privy policy 裡的地址值會被轉成 checksum 大小寫**，比對時要忽略大小寫。
- **改 Button 這類會用到 hook 的元件**，要加 `"use client"`，或從 `button-variants` 取樣式，否則 server component 會壞，例如 404 頁。
