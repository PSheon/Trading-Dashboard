## 7. 已知的陷阱

- **zsh 不會自動拆字：** 迴圈清單要用陣列，`F=(a b)`，再 `for f in $F`。
- **`gh run watch`：** 前景執行可能被權限系統擋下，改在背景跑，或改用 `gh run list` 查。
- **主網跟單第一次入金會被收 1 USDC 開戶費**（50 實際到帳 49），畫面上顯示 −$1.00 是正常的。
- **Hyperliquid 規則：**
  - 每單最低 10 USD；只有剛好全平的 reduce-only 單例外。
  - 新帳戶預設是 cross 20x，所以下單前一定要先設槓桿。
- **Privy policy 裡的地址值會被轉成 checksum 大小寫**，比對時要忽略大小寫。
- **改 Button 這類會用到 hook 的元件**，要加 `"use client"`，或從 `button-variants` 取樣式，否則 server component 會壞，例如 404 頁。
