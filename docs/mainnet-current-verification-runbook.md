## 3. 跟單與交易核對

1. 選用本輪實際有新交易、且幣種／執行方式符合當次能力的交易員。排行、分數與部分洞察資料不等於跟單適用性；ratio、既有持倉採納、未提供的市場或設定方式不能當作已支援。
2. 由 Paul 確認首筆配置、固定下單額、槓桿、授權期限與全部簽署內容，再啟動設定。核對資金送出、到帳、帳戶設定、代理授權、策略啟用；「跟單中」不是「已成交」。
3. 以原設定／策略身分核對領單成交、來源訊號、派送／執行紀錄、官方跟單成交與持倉、原資金帳本。ACK 不等於已完成結算；未知、確認中與已結算狀態要分開。
4. 檢查方向、數量、固定額／減倉口徑、費用、來源時間、派送時間與結算時間。沿用本輪明確定義的期限與證據時效，保留原 FAIL；不能延長門檻後改稱原測試通過。

完整收尾需核對原跟單帳戶在所有應覆蓋場域的持倉、掛單及可提餘額，核對原轉帳的唯一性與主錢包帳本，以及在途操作／風控負債的完成狀態。未完成的確認保留，不刪 browser recovery metadata 來繞過阻擋；不對其他使用者策略、權限或資金做清理。
