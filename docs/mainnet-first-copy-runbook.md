# 主網第一筆跟單操作手冊（Paul，2026-10-07 09:00）

Stage：<https://web-staging-9f98.up.railway.app>。上限：每筆跟單預算 ≤ 50 USDC、固定金額每筆 12–15 USDC、槓桿 ≤ 3x、最多 2 筆。

## 0. 開始前（主 session 確認）

1. Stage 已部署本次修正（見文末「需要部署」）。其中兩項沒部署就不能測：
   - 交易代理在主網的確認；
   - 成交後的結算。
2. **網頁停止按鈕在主網會被擋**（`lib/copy-live-stop.ts` 只接受 testnet）。修正在 `stop-mainnet.patch`，等你核准才會上線。上線之前，停止只能用第 6 步的後台緊急停止。

## 1. 入金到主錢包（約 5 分鐘）

1. 在 Arbitrum One（鏈 ID 42161）轉到主錢包地址 `0xfa82a7b2fce8017b0043eed5140805d55cfc7c06`：
   - **原生 USDC 103 枚**，合約 `0xaf88d065e77c8cC2239327C5EDb3A432268e5831`（不要用 USDC.e）；
   - 另轉 **ETH 0.0005 枚**付 gas。錢包有 ETH 就自己付 gas，不用依賴 Privy 代付；Privy 代付在 Privy 後台開關，我這邊看不到。
2. 進 Orbie，按右上 **儲值**。在對話框看到「**103 USDC 待轉入 Hyperliquid**」後，按 **轉入 Hyperliquid**，在錢包視窗簽名。
   - 這一步把 USDC 轉進 Bridge2（`0x2Df1c51E09aECF9cacB7bc98cB1742757f163dF7`），約 1 分鐘到帳。
   - 少於 5 USDC 不會入帳，而且拿不回來。
3. 金額怎麼算：
   - 2 筆 × 50 = 100；
   - 最後提款回 Arbitrum 的手續費 1；
   - 預留 2。
   - 每個新跟單帳戶第一次入金會被 Hyperliquid 收 **1 USDC 開戶費**。這筆費用從 50 裡扣，跟單帳戶實收 49，主錢包不用多準備。

## 3. 開始跟單（約 1–3 分鐘）

1. 打開 `/zh-TW/trader/<地址>`，在右側跟單卡把模式切到 **正式**。若看不到「正式」，代表你的帳號不在允許名單，或 Stage 不是主網。
2. 選 **順向**，金額填 **50**。
3. 展開 **更多設定**：
   - **跟單方式** 選 **固定金額**；
   - **每筆金額（USDC）** 填 12–15；
   - **最大槓桿** 填 ≤ 3。
4. 按 **開始跟單 $50**。等「正在準備跟單錢包與交易代理」（最多約 20 秒）。
5. 確認頁看到「**網路：Hyperliquid 主網（真實資金）**」和「預算 50 USDC」後，按 **確認並開始**。
   - 主錢包會簽兩樣東西：設定同意和入金。
   - Privy 也可能請你允許 Orbie 的簽署者（addSigners）。請允許，否則不會入金。
6. 進度依序是：入金送出 → 已入帳 → 帳戶設定 → 交易代理授權 → 費用授權 → 開始跟單。
   - 每一步通常幾秒。Hyperliquid 忙的時候，單一步驟可能等到約 65 秒。
   - 完成後，投資組合卡片顯示「跟單中」。
7. 要第二筆，換另一位交易員重複 1–6。

## 4. 預期會看到什麼

- 跟單只跟交易員**之後**的新交易：
  - 交易員每開一次倉，你這邊開 12–15 USDC 的倉；
  - 交易員減倉時，你按比例減；不足 10 USDC 的部分會累積，夠了才一起送出。
- 卡片的損益一開始會是 **−1.00**，這是開戶費（50 − 49）。
- 卡片上的權益與損益在主網目前顯示「—」。網頁的帳戶快照只接受 testnet；修正在 `snapshot-mainnet.patch`，等你核准。
  - 這段時間請用第 5 步的對帳指令，或 Hyperliquid 網頁上的跟單帳戶地址查看。

## 5. 唯讀對帳（不需任何金鑰）

```bash
node scripts/copy-harness/reconcile.mjs --stage \
  --leader <交易員地址> --follower <跟單帳戶地址> --since <開始跟單的 ISO 時間>
```

- 跟單帳戶地址在投資組合卡片的 **詳細資料** → **複製地址**。
- 這個指令只讀 Hyperliquid 公開資料：交易員和跟單帳戶的成交、持倉、權益。
- 結果裡的 `direction_mismatch` 表示兩邊方向不同。跟單前交易員已有的舊倉也會列出，這是正常的。
- 要連同 Orbie 的派單一起對帳，加 `--db ssh`。這是唯讀查 Stage 資料庫，需要 Railway SSH 金鑰。

## 6. 停止並拿回資金（約 2–5 分鐘）

1. 投資組合 → **正式** → 該跟單 → **停止跟單** → **確認停止**。
   - 前提：停止修正已上線（見第 0 步）。沒上線就用第 7 步。
2. 狀態依序是：停止中 → 資金返還中（自動返還中，不用簽名）→ 已停止。
   - 錢自動回主錢包，約 1 分鐘。
   - 沒有自動返還時，按 **全部返還主錢包** → **確認返還**。
3. 提回 Arbitrum：按 **提款**，輸入金額。
   - 手續費 1 USDC，從金額裡扣；畫面會顯示「預計到帳」。
   - 金額必須大於 1。
   - 約 3–4 分鐘到 Arbitrum。

## 7. 後台緊急停止（演練一次）

1. 打開 `/zh-TW/admin/copy` → **平台停止狀態** → **暫停新風險**。填寫原因後確認。
   - 新跟單會被拒絕，錯誤是 `copy_paused`。
   - 已有的倉位會照交易員的減倉繼續減。
2. 要全部出場：同一區按 **全部平倉**。
3. 演練完按 **恢復**。
