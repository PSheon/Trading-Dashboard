# Stage 測試流程（2026-10-07）

Stage：<https://web-staging-9f98.up.railway.app>（主網，只開放 Paul 的帳號）。

上限：每筆跟單預算 ≤ 50 USDC、固定金額每筆 12–15 USDC、槓桿 ≤ 3x、最多 2 筆。

**順序不能跳：** A 不用花錢，現在就能做；B 是 testnet 自動測試台，要全綠；B 全綠後才做 C 的主網真錢。每一步都寫了「應該看到」。看到的不一樣就停下來，照最後一節把資料傳給我。

## A. 不用花錢的檢查（約 20 分鐘，手機為主）

### A1. 登入與模式
1. 用手機打開 Stage，登入你的帳號（orbiefuncrypto）。
2. 進 **投資組合**。
   - 應該看到「正式」「模擬」兩個分頁，**沒有「測試網」**。
   - 「正式」分頁有「我的資金」卡片，總額 $0.00，旁邊有 **儲值**。
   - 舊的 testnet 跟單出現在「先前網路的跟單」，只能看，沒有按鈕。

### A2. 儲值視窗（只看，不轉帳）
1. 按 **儲值**。
2. 應該看到：
   - 網路 Arbitrum；
   - 你的地址 `0xfa82…7c06` 和 QR code；
   - 「僅可發送 Arbitrum 鏈上的 USDC · 最低 $5」。
3. 關掉視窗。

### A3. 跟單卡的金額規則（不按確認）
1. 打開交易員頁 `/zh-TW/trader/0x4a84f5a6e336b4f90c417c981d88c04fbeefa262`，點 **跟單**，切到 **正式**。
2. 依序輸入下面的金額，看按鈕的文字：
   - 60 → 按鈕顯示「上限 $50」，按了不會送出；
   - 5 → 按鈕顯示「最低 $11」；
   - 40 → 按鈕顯示「開始跟單 $40」。
3. 展開 **更多設定**：
   - 跟單方式只有 **固定金額**；
   - 每筆金額只能填 12–15；
   - 最大槓桿 ≤ 3。
4. **不要按開始。**
5. 切回 **模擬**：
   - 有「模擬」標籤，餘額是模擬的錢；
   - 模擬的最低金額跟正式不同，屬於正常。

### A4. 模擬跟單一輪（免費）
1. 用 **模擬** 跟同一位交易員 100 USDC，按開始。
   - 應該出現成功提示，按鈕轉圈時不能重按。
2. 投資組合 → **模擬** → 打開這筆跟單。
   - 「最大曝險」和「跟單資金」分開顯示。
3. 按 **停止跟單** → **確認停止**。狀態會變成已停止，模擬資金回到模擬餘額。
4. 設定 → **交易紀錄**：
   - 模擬的紀錄帶「模擬」標籤；
   - 錢回到你這邊是 **+**，轉出去是 **−**；
   - 顯示交易員名稱，不是 `#編號`。

### A5. 其他頁面
- **探索：** 篩選鈕寫「風格」；時間是「2 分鐘前」這種中文。
- **交易員頁：**
  - 期間選單是「全部／30天／7天」，資歷寫「X 個月」；
  - 分析若一直算不出來，約 40 秒後會顯示「暫時無法取得，稍後再試」和 **重試**。
- **洞察：**
  - 時間區間是「7天／30天／90天／全部」；
  - 熱力圖區塊不會是一整塊空白；
  - 資料有「更新於…」。
- **404：** 隨便打一個網址，按鈕寫「返回首頁」。

### A6. 後台緊急停止演練（admin，沒有正式跟單時做）
1. 打開 `/zh-TW/admin/copy` → **平台停止狀態** → **暫停新風險**，填原因後確認。
2. 回 A3 試開正式跟單（不用真的確認）。應該被拒絕，原因寫平台已暫停。
3. 回後台按 **全部平倉**，填原因後確認。現在沒有正式跟單，結果應該是「完成，0 筆」。
4. 按 **恢復**。

**A 的結果：** 全部符合就回我「A 全過」。有不符合的，截圖給我，並寫出是哪一步。

## B. testnet 自動測試台（我來跑，你只要先轉錢）

1. **你：** 從任何有 testnet USDC 的 Hyperliquid testnet 錢包，在 <https://app.hyperliquid-testnet.xyz> 按 **Send**，轉 **≥170 USDC** 到測試台交易員：
   `0xb56719305C461afd0dE51B9E5b7146FE045553e1`
2. **我：** 在本機 testnet，用 Stage 同樣的上限跑完整流程：
   ```
   node scripts/copy-harness/run.mjs --profile stage-caps --scenarios base,3,4,6,7,8,9,14
   ```
   測試台會自己登入測試帳號、開跟單、讓交易員照劇本下單，然後五方對帳：
   - 交易員成交；
   - 我們的派單；
   - 跟單成交；
   - 交易所持倉；
   - 投資組合 API。

   以下任何一種都算失敗：
   - 有一筆交易員的單沒跟到；
   - 下單金額不在 12–15；
   - 槓桿 > 3；
   - 最後沒平乾淨；
   - 出現不在允許清單裡的拒絕原因；
   - 重複下單。
3. **涵蓋的情境：**

   | 編號 | 情境 |
   | --- | --- |
   | base | 開倉 → 加倉 → 減半 → 平倉 → 開空 → 反手 → 平倉 |
   | 3 | 減倉金額低於 10 USD |
   | 4 | 有倉位時停止：應自動平倉、返還、變成已停止 |
   | 6 | 單一平倉進行中又按停止 |
   | 7 | 下單途中重啟 worker：不重複下單，後面照常跟 |
   | 8 | 一筆被拒後，後面的單照常跟。在 Stage 的上限下沒有符合條件的幣種，會顯示 SKIP |
   | 9 | 交易員 20 秒內分 3 次平倉，最後要平乾淨 |
   | 14 | 緊急停止：暫停時開倉被拒、減倉照跟，全部平倉會平倉並返還 |
4. **全綠才進 C。** 有紅的我會先修，再跑到綠，然後把結果表給你。

## C. 主網真錢（B 全綠之後）

照 `docs/mainnet-first-copy-runbook.md` 做。重點：

1. **入金：** 在 Arbitrum 轉 **原生 USDC 103 + ETH 0.0005** 到 `0xfa82a7b2fce8017b0043eed5140805d55cfc7c06`。到 Orbie 按 **儲值 → 轉入 Hyperliquid**，約 1 分鐘到帳。
2. **先開一筆就好：**
   - 交易員 `0x4a84f5a6…a262`（只做 BTC）或 `0xe7795fce…6ba7`（交易最頻繁）；
   - 正式、順向、50、固定 12–15、槓桿 3。
3. **確認頁：**
   - 網路是「Hyperliquid 主網（真實資金）」，預算 50，最大槓桿 3x；
   - 費用列寫明開戶費 1 USDC。
4. **進度：** 入金送出 → 已入帳 → 帳戶設定 → 交易代理授權 → 開始跟單（builder 費用這一步在主網會跳過）。完成後卡片顯示「跟單中」。
   - 權益約 $49，因為開戶費 1。
   - 損益 −$1.00 屬於正常。
5. **第一筆跟單成交後，到 Hyperliquid 網頁查跟單帳戶地址**（卡片 → 詳細資料 → 複製地址）：
   - 該幣種的槓桿是 **3x cross**；
   - 倉位的名目金額約 12–15 USD；
   - 交易員平倉後，跟單也平倉。
6. **對帳（唯讀）：**
   ```
   node scripts/copy-harness/reconcile.mjs --stage --leader <交易員> --follower <跟單帳戶> --since <開始時間>
   ```
7. **停止一次：** 卡片 → **停止跟單** → **確認停止**。
   - 狀態依序是：停止中 → 資金返還中 → 已停止；
   - 錢回主錢包，約 1–5 分鐘。
8. **第一筆跑一整天沒問題，再開第二筆**（換另一位交易員），確認兩筆互不干擾。
9. **提款回 Arbitrum：** 手續費 1，畫面會顯示「預計到帳」。
